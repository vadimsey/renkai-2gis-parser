# RENKAI Parser · 2ГИС

Отдельное приложение для Windows: поиск карточек химчистки мебели в 2ГИС, отбор по наличию сайта в карточке и экспорт данных.

## Скачать и запустить

Версия 0.1.7 добавляет раздел **«База карточек»** в левом меню: все сохранённые карточки из прошлых запусков, поиск по названию, городу и телефону, фильтры «Все / Подходят / С сайтом» и страницы по 50 строк. **«Скачать подборку»** сохраняет весь результат выбранного фильтра в HTML, CSV или JSON через диалог выбора файла. **«Копия SQLite»** сохраняет полную резервную копию локальной базы, включая историю исключений. Рабочая база при сохранении не перезаписывается.

Данные читаются из `%LOCALAPPDATA%\RENKAI-2GIS\history.sqlite3`. Для переноса своей истории на другой компьютер закройте приложение там и замените этот файл своей копией. В публичном выпуске находится только пустая база; личные карточки не публикуются.

1. Откройте [последний выпуск](../../releases/latest) и скачайте `RENKAI-2GIS.exe`.
2. Запустите файл. На компьютере должен быть установлен Google Chrome.
3. Выберите город из подсказок: код 2ГИС подставится автоматически из справочника. Перед запуском бэкенд повторно определит код по названию, чтобы не использовать код предыдущего города. Поддерживаются коды с `_`, например `n_novgorod`.
4. Оставьте количество пустым, чтобы не задавать лимит, или укажите число, затем начните поиск.
5. Если 2ГИС попросит подтвердить доступ, выполните это вручную в открытом браузере. При наличии подходящих карточек кнопка экспорта сохранит HTML, CSV и JSON.

Приложение проверяет отсутствие сайта только в полученной карточке 2ГИС. Это не доказывает, что сайта нет в интернете. В версии 0.1.4 все полученные карточки без обнаруженного сайта включаются в подходящие, даже при неполных контактах или без отдельного подтверждения услуги. Поисковый запрос остаётся «химчистка мебели».

В версии 0.1.3 сбор читает данные обычных публичных страниц 2ГИС в браузере исходного движка. Отдельные XHR-запросы к `catalog.api.2gis.ru` для получения контактов больше не нужны. Парсер сохраняет контакты из ответа HTML, поэтому последующий необязательный переход страницы на Сбер ID не теряет уже полученную карточку.

Данные услуг могут дополняться прайсом той же компании, но больше не блокируют попадание в подходящие. Telegram, VK, Max и WhatsApp не считаются отдельным сайтом. Прикреплённый сайт по-прежнему исключает компанию.

Проверка готового EXE 0.1.3 в Краснодаре 10 ноября 2026: за 139 секунд получены 24 уникальные компании, из них 1 подходит, 18 имеют сайт в карточке, по 5 недостаточно подтверждения. Две недоступные карточки пропущены. HTML с подходящей компанией прошёл обратный импорт. Отдельный прогон исходников по другим страницам дал 23 уникальные компании: 3 подходят, 14 имеют сайт, по 6 недостаточно подтверждения. Это отдельные прогоны, их счётчики не суммируются. Недоступные отдельные карточки пропускаются с сохранением результатов; при трёх последовательных сбоях или ограничении доступа сбор останавливается с причиной.

## База просмотренных карточек (0.1.5)

В версии 0.1.6 карточки с обнаруженной в контактах ссылкой на Telegram-бота исключаются из подходящих и удаляются из таблицы карточек. Для защиты от повторного появления сохраняются только ID, причина и URL доказательства в списке исключений. Признаки ссылки на бота: Telegram-адрес с именем, оканчивающимся на `bot`, либо параметрами запуска бота/мини-приложения. Обычные контакты, каналы и приглашения Telegram сами по себе не исключаются. Учитываются все Telegram-ссылки карточки. Известные боты из старой базы удаляются при открытии, повторный импорт их не возвращает.

При открытии приложения восстанавливается последний сохранённый запуск, чтобы его результаты можно было посмотреть и экспортировать без повторного поиска.

Все успешно прочитанные карточки сохраняются в локальную SQLite-базу `%LOCALAPPDATA%\RENKAI-2GIS\history.sqlite3`: ID и ссылка 2ГИС, дата, название, город, телефоны, сайты и остальные полученные данные. Сохраняются также компании с сайтом. При запуске импортируются прошлые результаты из папки `runs`. Удаление отдельного отчёта или обновление EXE не очищает базу.

Повторный поиск пропускает известные ID до открытия карточек и продолжает следующие страницы. Предел поиска относится к новым прочитанным карточкам. Если вся выдача уже известна, поиск завершается без ошибки, новых результатов может быть 0. В интерфейсе видны пропуски и размер базы. Разные филиалы имеют отдельные ID; записи прошлых запусков, объединённые по телефону, импортируются с ID из сохранённых источников.

Ошибки чтения и CAPTCHA не отмечаются как успешно просмотренные. Два одновременных запуска используют временные резервирования карточек; после аварийного закрытия резервирование истекает через 5 минут. База локальная для пользователя Windows; у друга на другом компьютере своя история.

## Сборка из исходников

На Windows с Python 3.12:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m PyInstaller --noconfirm RENKAI-2GIS.spec
```

Файл будет создан в `dist/RENKAI-2GIS.exe`. Данные рабочих запусков хранятся в `%LOCALAPPDATA%\RENKAI-2GIS\runs`.

Офлайн-проверки разработчика: `pip install pytest playwright`, затем `python -m pytest tests -q`. Браузерный тест использует установленный Chrome. Тесты подставляют искусственные страницы и не запускают массовый сбор.

Движок содержит исходный код [Eroloft/parser-2gis-new](https://github.com/Eroloft/parser-2gis-new) под LGPL-3.0; информация об изменениях и лицензия находятся в [third_party](third_party/README.md).
